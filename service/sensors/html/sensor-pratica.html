Desafio Prático 01

💡 Iluminação Inteligente

Arduino UNO LED Sensor de Presença (PIR) Sensor de Luminosidade (LDR)

Circuito que controla automaticamente um LED combinando as informações de dois sensores: a presença de uma pessoa no ambiente e o nível de luminosidade. A lâmpada só é acionada quando realmente há necessidade, evitando consumo desnecessário de energia.

🎬 Demonstração & Vídeo Explicativo

Demonstração do funcionamento e explicação do uso dos sensores na bancada.

⚙️ Lógica do Sistema

  • Pessoa presente + ambiente escuro → LED ligado
  • Pessoa presente + ambiente claro → LED desligado
  • Sem pessoa no local → LED desligado
Como os sensores atuam: o sensor PIR fornece um sinal digital (HIGH/LOW) indicando movimento, enquanto o LDR fornece um valor analógico de 0 a 1023 proporcional à luz. O LED só é ligado quando as duas condições são verdadeiras ao mesmo tempo.
🔗 Circuito no Tinkercad (adicionar link)

💻 Código do Arduino

// Desafio 1 - Iluminação Inteligente
// Componentes: LED, Sensor de Presença (PIR) e Sensor de Luminosidade (LDR)

const int PINO_PIR = 2;     // Saída digital do sensor de presença
const int PINO_LDR = A0;    // Saída analógica do sensor de luminosidade
const int PINO_LED = 8;     // LED controlado pelo sistema

const int LIMIAR_ESCURO = 500; // Abaixo deste valor o ambiente é considerado escuro

void setup() {
  pinMode(PINO_PIR, INPUT);
  pinMode(PINO_LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  bool presenca = digitalRead(PINO_PIR) == HIGH;   // Há alguém no ambiente?
  int luminosidade = analogRead(PINO_LDR);         // Nível de luz (0 a 1023)
  bool ambienteEscuro = luminosidade < LIMIAR_ESCURO;

  // O LED só liga quando as DUAS condições são verdadeiras
  if (presenca && ambienteEscuro) {
    digitalWrite(PINO_LED, HIGH);
  } else {
    digitalWrite(PINO_LED, LOW);
  }

  Serial.print("Presença: ");
  Serial.print(presenca);
  Serial.print(" | Luminosidade: ");
  Serial.println(luminosidade);

  delay(200);
}
Desafio Prático 02

🚗 Estacionamento Inteligente

Arduino UNO LED Sensor Ultrassônico (HC-SR04) Potenciômetro

Sistema de auxílio ao estacionamento que mede a distância de um obstáculo com o sensor ultrassônico e permite ao usuário ajustar manualmente a distância de segurança através do potenciômetro.

🎬 Demonstração & Vídeo Explicativo

Testes com diferentes distâncias e posições reguladas no potenciômetro.

▶ Assistir no YouTube Shorts

⚙️ Lógica do Sistema

  • Objeto distante (> limite) → LED desligado
  • Objeto se aproximando → LED piscando (quanto mais perto, mais rápido)
  • Objeto dentro da distância mínima (≤ limite / 2) → LED ligado contínuo
Desafio adicional implementado: o LED pisca cada vez mais rapidamente conforme o obstáculo se aproxima, atuando como alerta visual progressivo. O potenciômetro altera diretamente o comportamento dinâmico do sistema, definindo o valor da distância limite (5 a 50 cm) usada nas comparações.
🔗 Circuito no Tinkercad (adicionar link)

💻 Código do Arduino

// Desafio 2 - Estacionamento Inteligente
// Componentes: LED, Sensor Ultrassônico HC-SR04 e Potenciômetro

const int PINO_TRIGGER = 9;
const int PINO_ECHO = 10;
const int PINO_POT = A0;
const int PINO_LED = 8;

void setup() {
  pinMode(PINO_TRIGGER, OUTPUT);
  pinMode(PINO_ECHO, INPUT);
  pinMode(PINO_LED, OUTPUT);
  Serial.begin(9600);
}

long medirDistanciaCm() {
  digitalWrite(PINO_TRIGGER, LOW);
  delayMicroseconds(2);
  digitalWrite(PINO_TRIGGER, HIGH);
  delayMicroseconds(10);
  digitalWrite(PINO_TRIGGER, LOW);

  long duracao = pulseIn(PINO_ECHO, HIGH);
  return duracao * 0.0343 / 2; // Velocidade do som (~343 m/s)
}

void loop() {
  // O potenciômetro define a distância limite de segurança (5 a 50 cm)
  int leituraPot = analogRead(PINO_POT);
  int distanciaLimite = map(leituraPot, 0, 1023, 5, 50);

  long distancia = medirDistanciaCm();

  if (distancia > distanciaLimite) {
    // Objeto distante -> LED desligado
    digitalWrite(PINO_LED, LOW);

  } else if (distancia > distanciaLimite / 2) {
    // Objeto se aproximando -> LED piscando (quanto mais perto, mais rápido)
    int intervalo = map(distancia, distanciaLimite / 2, distanciaLimite, 50, 400);
    digitalWrite(PINO_LED, HIGH);
    delay(intervalo);
    digitalWrite(PINO_LED, LOW);
    delay(intervalo);

  } else {
    // Objeto dentro da distância mínima -> LED ligado continuamente
    digitalWrite(PINO_LED, HIGH);
  }

  Serial.print("Distância: ");
  Serial.print(distancia);
  Serial.print(" cm | Limite definido: ");
  Serial.print(distanciaLimite);
  Serial.println(" cm");
}
Desafio Prático 03

🌡️ Ambiente Inteligente

Arduino UNO LEDs (verde, vermelho, amarelo) Sensor de Temperatura Sensor de Umidade (DHT11)

Sistema de monitoramento de uma estufa, capaz de acompanhar a temperatura e a umidade do ambiente. Os LEDs funcionam como indicadores visuais das condições, sinalizando inclusive quando duas situações críticas acontecem ao mesmo tempo.

🎬 Demonstração & Vídeo Explicativo

Testes simulando diferentes temperaturas e níveis críticos de umidade.

▶ Assistir no YouTube Shorts

⚙️ Lógica do Sistema

  • Temperatura e umidade adequadas → LED verde ligado
  • Temperatura acima do limite (> 30°C) → LED vermelho ligado
  • Umidade abaixo do limite (< 40%) → LED amarelo ligado
Desafio adicional implementado: cada LED representa uma condição independente. Quando ocorre temperatura alta e umidade baixa ao mesmo tempo, o vermelho e o amarelo acendem juntos, indicando visualmente as duas condições críticas simultâneas. O LED verde só acende quando as variáveis estão dentro do padrão ideal.
🔗 Circuito no Tinkercad (adicionar link)

💻 Código do Arduino

// Desafio 3 - Ambiente Inteligente (Estufa)
// Componentes: LEDs (verde, vermelho, amarelo) e Sensor DHT (temperatura e umidade)

#include <DHT.h>

#define PINO_DHT 2
#define TIPO_DHT DHT11

DHT dht(PINO_DHT, TIPO_DHT);

const int PINO_LED_VERDE = 8;
const int PINO_LED_VERMELHO = 9;
const int PINO_LED_AMARELO = 10;

const float TEMP_LIMITE = 30.0; // Acima disso -> temperatura elevada
const float UMID_LIMITE = 40.0; // Abaixo disso -> umidade inadequada

void setup() {
  dht.begin();
  pinMode(PINO_LED_VERDE, OUTPUT);
  pinMode(PINO_LED_VERMELHO, OUTPUT);
  pinMode(PINO_LED_AMARELO, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  float temperatura = dht.readTemperature();
  float umidade = dht.readHumidity();

  if (isnan(temperatura) || isnan(umidade)) {
    Serial.println("Falha na leitura do sensor DHT!");
    delay(2000);
    return;
  }

  bool temperaturaAlta = temperatura > TEMP_LIMITE;
  bool umidadeBaixa = umidade < UMID_LIMITE;

  // Cada LED indica uma condição; mais de um pode acender ao mesmo tempo
  digitalWrite(PINO_LED_VERMELHO, temperaturaAlta ? HIGH : LOW);
  digitalWrite(PINO_LED_AMARELO, umidadeBaixa ? HIGH : LOW);

  // O verde só acende quando as duas variáveis estão dentro do ideal
  digitalWrite(PINO_LED_VERDE, (!temperaturaAlta && !umidadeBaixa) ? HIGH : LOW);

  Serial.print("Temp: ");
  Serial.print(temperatura);
  Serial.print(" °C | Umidade: ");
  Serial.print(umidade);
  Serial.println(" %");

  delay(200);
}
