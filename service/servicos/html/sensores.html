Sensoriamento & Automação

Sensores

Os sensores são os olhos e ouvidos dos sistemas automatizados. Dispositivos capazes de detectar grandezas físicas, químicas ou ambientais e convertê-las em sinais elétricos interpretáveis.

Conceito

O que é um Sensor?

Um sensor é um dispositivo que detecta uma grandeza física e produz uma saída mensurável relacionada a ela. A grandeza detectada é chamada de variável de processo.

Sensores são a base de qualquer sistema automatizado: sem eles, não há percepção do ambiente e, consequentemente, nenhuma ação inteligente é possível.

Exemplos do Cotidiano

Sensores de temperatura em climatizadores, sensores de movimento em iluminação automática, sensores de presença em portas automáticas e sensores de gás em detectores de fumaça.

Desafio Prático 01

Iluminação Inteligente

Arduino UNO LED Sensor de Presença (PIR) Sensor de Luminosidade (LDR)

Circuito que controla automaticamente um LED combinando as informações de dois sensores: a presença de uma pessoa no ambiente e o nível de luminosidade. A lâmpada só é acionada quando realmente há necessidade.

Demonstração & Vídeo Explicativo

Demonstração do funcionamento e explicação dos sensores na bancada.

Lógica do Sistema

  • Pessoa presente + ambiente escuro → LED ligado
  • Pessoa presente + ambiente claro → LED desligado
  • Sem pessoa no local → LED desligado
Como os sensores atuam: o PIR fornece sinal digital (HIGH/LOW) indicando movimento, e o LDR fornece valor analógico (0 a 1023) proporcional à luz.

Código do Arduino

const int PINO_PIR = 2;     // Saída digital do PIR
const int PINO_LDR = A0;    // Saída analógica do LDR
const int PINO_LED = 8;     // LED controlado

const int LIMIAR_ESCURO = 500;

void setup() {
  pinMode(PINO_PIR, INPUT);
  pinMode(PINO_LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  bool presenca = digitalRead(PINO_PIR) == HIGH;
  int luminosidade = analogRead(PINO_LDR);
  bool ambienteEscuro = luminosidade < LIMIAR_ESCURO;

  if (presenca && ambienteEscuro) {
    digitalWrite(PINO_LED, HIGH);
  } else {
    digitalWrite(PINO_LED, LOW);
  }
  delay(200);
}
Desafio Prático 02

Estacionamento Inteligente

Arduino UNO LED Sensor Ultrassônico (HC-SR04) Potenciômetro

Sistema de auxílio ao estacionamento que mede a distância de um obstáculo com o sensor ultrassônico e permite ao usuário ajustar manualmente a distância de segurança através do potenciômetro.

Demonstração & Vídeo Explicativo

Testes com diferentes distâncias e posições reguladas no potenciômetro.

▶ Assistir no YouTube Shorts

Lógica do Sistema

  • Objeto distante (> limite) → LED desligado
  • Objeto se aproximando → LED piscando com frequência dinâmica
  • Distância mínima (≤ limite / 2) → LED ligado contínuo
Desafio dinâmico: O LED pisca proporcionalmente à distância, oferecendo alerta sonoro e visual progressivo ajustado em tempo real pelo potenciômetro.

Código do Arduino

const int PINO_TRIGGER = 9;
const int PINO_ECHO = 10;
const int PINO_POT = A0;
const int PINO_LED = 8;

void setup() {
  pinMode(PINO_TRIGGER, OUTPUT);
  pinMode(PINO_ECHO, INPUT);
  pinMode(PINO_LED, OUTPUT);
  Serial.begin(9600);
}

long medirDistanciaCm() {
  digitalWrite(PINO_TRIGGER, LOW);
  delayMicroseconds(2);
  digitalWrite(PINO_TRIGGER, HIGH);
  delayMicroseconds(10);
  digitalWrite(PINO_TRIGGER, LOW);
  long duracao = pulseIn(PINO_ECHO, HIGH);
  return duracao * 0.0343 / 2;
}

void loop() {
  int leituraPot = analogRead(PINO_POT);
  int distanciaLimite = map(leituraPot, 0, 1023, 5, 50);
  long distancia = medirDistanciaCm();

  if (distancia > distanciaLimite) {
    digitalWrite(PINO_LED, LOW);
  } else if (distancia > distanciaLimite / 2) {
    int intervalo = map(distancia, distanciaLimite / 2, distanciaLimite, 50, 400);
    digitalWrite(PINO_LED, HIGH);
    delay(intervalo);
    digitalWrite(PINO_LED, LOW);
    delay(intervalo);
  } else {
    digitalWrite(PINO_LED, HIGH);
  }
}
Desafio Prático 03

Ambiente Inteligente (Estufa)

Arduino UNO LEDs RGB / Status Sensor de Temperatura Sensor de Umidade (DHT11)

Sistema de monitoramento de estufa capaz de acompanhar temperatura e umidade com alerta simultâneo em condições críticas.

Demonstração & Vídeo Explicativo

Testes simulando diferentes temperaturas e níveis críticos de umidade.

▶ Assistir no YouTube Shorts

Lógica do Sistema

  • Temperatura e umidade adequadas → LED verde ligado
  • Temperatura alta (> 30°C) → LED vermelho ligado
  • Umidade baixa (< 40%) → LED amarelo ligado
Condições simultâneas: Se ambas as anomalias ocorrerem, vermelho e amarelo acendem juntos para alertar o operador imediatamente.

Código do Arduino

#include <DHT.h>
#define PINO_DHT 2
#define TIPO_DHT DHT11
DHT dht(PINO_DHT, TIPO_DHT);

const int PINO_LED_VERDE = 8;
const int PINO_LED_VERMELHO = 9;
const int PINO_LED_AMARELO = 10;

void setup() {
  dht.begin();
  pinMode(PINO_LED_VERDE, OUTPUT);
  pinMode(PINO_LED_VERMELHO, OUTPUT);
  pinMode(PINO_LED_AMARELO, OUTPUT);
}

void loop() {
  float temp = dht.readTemperature();
  float umid = dht.readHumidity();

  bool tempAlta = temp > 30.0;
  bool umidBaixa = umid < 40.0;

  digitalWrite(PINO_LED_VERMELHO, tempAlta ? HIGH : LOW);
  digitalWrite(PINO_LED_AMARELO, umidBaixa ? HIGH : LOW);
  digitalWrite(PINO_LED_VERDE, (!tempAlta && !umidBaixa) ? HIGH : LOW);

  delay(200);
}
