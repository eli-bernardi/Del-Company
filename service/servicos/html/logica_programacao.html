Linguagens Interpretadas

Executadas diretamente por um interpretador, linha por linha. Facilita testes, mas pode ser mais lento.

PythonJavaScriptPHPRuby

O código é convertido para código de máquina antes de ser executado. Mais rápido e eficiente.

Linguagens Usadas

Exemplos de Código

Hello World em Diferentes Linguagens

Python
print("Olá, mundo!")
JavaScript
console.log("Olá, mundo!");
PHP
<?php echo "Olá, mundo!"; ?>
C
#include <stdio.h>
int main() {
    printf("Olá, mundo!");
    return 0;
}
C++
#include <iostream>
using namespace std;
int main() {
    cout << "Olá, mundo!";
    return 0;
}
Go (Golang)
package main
import "fmt"
func main() {
    fmt.Println("Olá, mundo!")
}
Web

HTML, CSS e JavaScript

Exemplificação | Funcionalidade | Utilização

HTML

HyperText Markup Language — base de toda página web. Responsável por estruturar o conteúdo como textos, imagens, links e botões.

CSS

Cascading Style Sheets — responsável pela aparência. Define cores, fontes, espaçamentos, tamanhos e animações.

JavaScript

Linguagem de programação que dá vida e interatividade à web. Responsável pelo dinamismo, requisições assíncronas, manipulação do DOM e lógica no navegador.

Ferramentas

IDE — Ambiente de Desenvolvimento Integrado

Exemplificação | Funcionalidade | Utilização

Uma IDE reúne em um único lugar todas as ferramentas necessárias para programar: escrever, testar e depurar códigos com autocompletar, destaque de sintaxe e controle de versões.

Visual Studio Code

IDE mais popular do mundo. Leve, personalizável, suporta centenas de extensões. Desenvolvida pela Microsoft.

IntelliJ IDEA

Voltada para Java, mas suporta várias linguagens. Excelente para sugestão de código e depuração avançada.

Google Antigravity

Ambiente de desenvolvimento integrado (IDE) agente de última geração criado pela Google DeepMind, com IA nativa e automação completa de tarefas.

Conceitos-chave

Elementos Fundamentais da Programação

Elemento Função
Variáveis Armazenam informações temporárias como números, textos ou resultados de cálculos.
Condicionais Permitem executar ações diferentes dependendo de uma condição (if, else, switch).
Laços de Repetição Repetem um trecho de código várias vezes (for, while, do...while).
Funções Agrupam comandos reutilizáveis ao longo do programa.
Operadores Lógicos Comparar valores e tomar decisões lógicas (AND, OR, NOT).
