Tecnologia da Informação

A TI conecta computadores, sistemas e pessoas, garantindo que a informação chegue onde precisa de forma rápida e segura.

Hardware

Componentes de um Sistema de TI

Exemplificação | Funcionalidade | Utilização

Placa-Mãe

Base do computador. Conecta e faz a comunicação entre todos os componentes — CPU, memória, armazenamento, GPU e periféricos.

Processador (CPU)

"Cérebro" da máquina. Realiza cálculos e executa as instruções dos programas.

Memória RAM

Memória temporária, usada enquanto o computador está ligado. Mais RAM = mais programas ao mesmo tempo.

Outros componentes essenciais
ArmazenamentoFonte de AlimentaçãoPlaca de VídeoCoolerPeriféricos

Sistemas Operacionais

Exemplificação | Funcionalidade | Utilização

Um sistema operacional gerencia tudo: como os aplicativos rodam, uso da memória, arquivos, conexões e periféricos.

Windows

O mais popular no mundo dos PCs. Compatível com praticamente todos os programas. Muito utilizado em empresas, escolas e escritórios.

macOS

Sistema exclusivo da Apple. Aposta em desempenho, simplicidade e integração com outros dispositivos da marca.

Linux

Livre e altamente personalizável. Muito usado por desenvolvedores e servidores.

Sistema de Arquivos

Sistemas de Arquivos (CMD)

Exemplificação | Funcionalidade | Utilização

Estruturas que organizam e armazenam dados em dispositivos de armazenamento. O CMD (Command Prompt) permite interação com o computador através de comandos de texto.

FAT32 — Compatível, limitado a 4GB NTFS — Padrão Windows, seguro exFAT — Ideal para pendrives ext4 — Padrão Linux
Modo Texto — Terminal / CMD
# Windows (CMD)
cd C:\Users\MeuUsuario\Documentos
dir
mkdir Projeto
copy arquivo.txt C:\Backup\arquivo.txt

# Linux / macOS (Terminal)
cd /home/usuario/Documentos
ls -la
mkdir projeto
cp arquivo.txt /backup/arquivo.txt
rm arquivo.txt

Automação

Scripts em bash ou PowerShell para tarefas repetitivas.

Acesso Remoto

Conexão via SSH com total controle do sistema.

Modo Gráfico

Explorer / Gerenciador de Arquivos para uso intuitivo com ícones e menus.
