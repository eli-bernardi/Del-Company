Fundamentos de Banco de Dados

Os bancos de dados são a espinha dorsal dos sistemas modernos, armazenando e gerenciando dados de forma estruturada para tomada de decisões inteligentes.

Conceito

O que é um SGBD? Tipos e Aplicações

Definição | Classificação | Utilização

O SGBD (Sistema Gerenciador de Banco de Dados) é um software responsável por armazenar, organizar e manipular dados de forma estruturada, garantindo segurança, consistência e acesso controlado.

Relacional (RDBMS)

Dados organizados em tabelas com relações definidas.

MySQLPostgreSQLOracle

Não Relacional (NoSQL)

Dados flexíveis sem estrutura fixa de tabelas.

MongoDBRedisCassandra

Distribuído

Dados distribuídos em múltiplos servidores.

Google SpannerCockroachDB
Sistemas Bancários

Transações financeiras e controle de contas.

E-commerce

Catálogo de produtos, pedidos e clientes.

Redes Sociais

Perfis de usuários, posts e interações.

Estrutura

Dicionário de Dados e Tipos

Definição | Estrutura | Tipos de Dados

O dicionário de dados documenta todas as informações de um banco: nomes de tabelas, colunas, tipos e restrições. É essencial para manter a padronização e clareza do sistema.

CampoTipoTamanhoDescriçãoRestrições
id_clienteINT11Identificador único do clientePRIMARY KEY, AUTO_INCREMENT
nomeVARCHAR100Nome completo do clienteNOT NULL
emailVARCHAR255E-mail do clienteUNIQUE, NOT NULL
data_nascimentoDATE—Data de nascimentoNULL
ativoBOOLEAN—Status do clienteDEFAULT TRUE

Numéricos

  • INT — Números inteiros
  • DECIMAL — Números decimais precisos
  • FLOAT — Ponto flutuante
  • BOOLEAN — TRUE/FALSE

Textuais

  • VARCHAR(n) — Texto de tamanho variável
  • CHAR(n) — Texto de tamanho fixo
  • TEXT — Textos longos
  • ENUM — Lista de valores pré-definidos

Data/Hora

  • DATE — Data (YYYY-MM-DD)
  • DATETIME — Data e hora
  • TIMESTAMP — Marca temporal
  • TIME — Horário (HH:MM:SS)
Modelagem

DER e MER

Conceito | Estrutura | Diferença

A modelagem de banco de dados é o processo de planejar como os dados serão organizados e relacionados, garantindo integridade, consistência e fácil manutenção.

DER — Diagrama Entidade-Relacionamento

Representação gráfica das entidades e seus relacionamentos.

⬜Entidades — Retângulos
⬭Atributos — Elipses
◇Relacionamentos — Losangos

MER — Modelo Entidade-Relacionamento

Versão extendida do DER com mais detalhes conceituais.

1:1Um para Um
1:NUm para Muitos
N:MMuitos para Muitos

Diagrama DER — Sistema de Biblioteca

Livro

Informações sobre os livros disponíveis

id_livro, titulo, autor, ano
Usuário

Cadastro de usuários da biblioteca

id_usuario, nome, email, telefone
Empréstimo

Registro de empréstimos de livros

id_emprestimo, data_emprestimo, data_devolucao

Diagrama MER — Cardinalidades

1:1

Um usuário tem um único perfil.

1:N

Um usuário pode fazer vários empréstimos.

N:M

Um livro pode ter vários autores.
